1. Les variables

Une variable est une zone mémoire utilisée pour stocker une valeur. En Python, il n'est pas nécessaire de déclarer le type de la variable.

Exemple en Python

age = 17
nom = "Ahmed"
moyenne = 15.5

Exemple en Algorithmique

Algorithme Exemple
Variables
    age : entier
    nom : chaîne
    moyenne : réel
Début
    age ← 17
    nom ← "Ahmed"
    moyenne ← 15.5
Fin

Types de données

3. Les conditions

Les conditions permettent d'exécuter des instructions selon qu'une condition est vraie ou fausse.

Structure en Python

if condition:
    instruction
else:
    instruction

Exemple

age = int(input("Donner votre âge : "))

if age >= 18:
    print("Majeur")
else:
    print("Mineur")

En Algorithmique

Si age >= 18 Alors
    Ecrire("Majeur")
Sinon
    Ecrire("Mineur")
FinSi

4. La boucle While

La boucle while permet de répéter des instructions tant qu'une condition est vraie.

Python

i = 1

while i <= 5:
    print(i)
    i = i + 1

Algorithmique

i ← 1

Tant que i <= 5 Faire
    Ecrire(i)
    i ← i + 1
FinTantQue

Résultat

1 - 2 - 3 - 4 - 5

5. La boucle For

La boucle for permet de répéter une instruction un nombre déterminé de fois.

Python

for i in range(1, 6):
    print(i)

Algorithmique

Pour i de 1 à 5 Faire
    Ecrire(i)
FinPour

Comparaison While / For

WhileFor
Répétition basée sur une conditionRépétition généralement basée sur un nombre de tours
La condition est testée à chaque tourUtilisé souvent avec range()
while i < 10:for i in range(10):

7. Les fonctions

Une fonction est un bloc d'instructions qui permet de réaliser une tâche précise et qui peut être réutilisé.

Python

def somme(a, b):
    return a + b

resultat = somme(5, 3)
print(resultat)

Algorithmique

Fonction somme(a, b : entier) : entier
Début
    Retourner a + b
Fin
